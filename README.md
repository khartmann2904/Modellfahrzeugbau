# Autonomous Wire-Tracking Vehicle (Inductive Line Tracking)

This project was developed as part of the academic practical course **Model Vehicle Engineering** at the **Technical University of Braunschweig**. The goal was to design, implement, and optimize the sensor systems, analog signal conditioning, and control logic for an autonomous model vehicle that follows a current-carrying wire embedded in the track.

The main focus was building a reliable inductive sensing front-end — from coil selection and analog filtering all the way to a closed-loop PID controller driving the steering servo.

## Contributions

My core focus in this project centered on sensor design, analog signal conditioning, and closed-loop steering control:

- **Inductive Sensor Array** — Selected, tuned, and positioned induction coils to detect the alternating magnetic field generated by the track wire.
- **Analog Signal Conditioning** — Designed bandpass filtering and amplification stages to suppress external noise and condition the signal for ADC conversion.
- **Signal Processing & Control Loop** — Implemented signal normalization algorithms to compute cross-track error, paired with a PID controller to drive the steering servo.

## Technologies

- **Hardware:** Induction coils, operational amplifiers (op-amps), bandpass filters, ADC, servo PWM control.
- **Embedded Software:** C/C++, real-time signal processing, closed-loop PID control.
- **Testing & Validation:** Measurement setups to evaluate signal integrity across varying wire distances and approach angles.

## How It Works

1. **Magnetic Field Generation** — An AC signal passing through the floor wire generates a circular alternating magnetic field.
2. **Inductive Sensing** — Two symmetrical coils mounted at the vehicle's front induce an AC voltage proportional to the distance from the wire.
3. **Cross-Track Error Calculation:**

   $$\text{Error} = \frac{V_{\text{left}} - V_{\text{right}}}{V_{\text{left}} + V_{\text{right}}}$$

   Normalization ensures immunity against signal strength variations and height fluctuations.
4. **Steering Control** — A PID controller processes the error value to continuously adjust the servo angle, keeping the vehicle centered on the wire.

## Notes

This project was primarily a hands-on exercise in analog sensor design and closed-loop control — tuning the coil-and-filter front-end to get a clean, reliable error signal turned out to be just as important as the control logic itself.
